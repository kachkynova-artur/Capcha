# CaptchaLab — лабораторная работа по тестированию (Django)

Что сделано:
1. **Капча при авторизации**: на форме входа картинка с примером (например `7 + 3 = ?`).
   Ответ хранится в сессии, капча одноразовая, после каждой попытки генерируется новая.
   Своя реализация, сторонние библиотеки не нужны (`accounts/captcha.py`).
2. **Тесты** (`accounts/tests.py`, 50 штук): капча, регистрация, авторизация, личный кабинет.
3. **Вход с учётом капчи**: все тесты входа решают капчу (ответ берётся из сессии),
   отдельно проверяются неверная, пустая, нечисловая и повторно использованная капча.
4. **Отчёт в Word через Django**: собственный тест-раннер (`accounts/test_runner.py`,
   подключён в `settings.py` через `TEST_RUNNER`). После `python manage.py test`
   в папке `reports/` появляется файл `test_report_ГГГГММДД_ЧЧММСС.docx`.
   Последний отчёт можно скачать и из личного кабинета (кнопка «Скачать отчёт о тестах»).

## Запуск в Visual Studio 2022

1. В Visual Studio Installer должна быть включена рабочая нагрузка **«Разработка на Python»**.
2. Распакуйте архив и откройте **CaptchaLab.sln**
   (если проект не открывается: *Файл → Открыть → Папка* и выберите папку проекта).
3. В «Обозревателе решений» щёлкните правой кнопкой по **Python Environments →
   Add Environment → Virtual environment** — Visual Studio создаст окружение и
   предложит установить пакеты из `requirements.txt` (Django и python-docx).
4. Откройте терминал (*Вид → Терминал*) и выполните:
   ```
   python manage.py migrate
   ```
5. Нажмите **F5** — откроется сайт. Регистрация: `/register/`, вход: `/login/`, кабинет: `/profile/`.

## Запуск тестов и получение Word-отчёта

В терминале Visual Studio:
```
python manage.py test accounts -v 2
```
В конце вывода будет строка
`Отчёт о тестировании сохранён в Word: ...\reports\test_report_....docx`.

В отчёте: общие сведения, итоги (всего/пройдено/не пройдено, процент),
результаты по модулям, таблица всех тест-кейсов с цветной отметкой результата,
описание ошибок (если есть) и заключение.

> Запускайте тесты именно командой `manage.py test`: «Обозреватель тестов» Visual Studio
> использует свой запускатель и Word-отчёт не создаёт.

## Структура
```
accounts/captcha.py      — генерация, проверка и картинка капчи
accounts/forms.py        — формы входа (с капчей), регистрации, профиля
accounts/views.py        — страницы
accounts/tests.py        — автотесты
accounts/test_runner.py  — тест-раннер, собирающий результаты
accounts/word_report.py  — формирование .docx (python-docx)
templates/               — HTML-шаблоны
reports/                 — сюда сохраняются отчёты
```
